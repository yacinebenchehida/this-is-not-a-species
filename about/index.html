About the project

A personal playground for exploring life's complexity.

Made for curiosity

This is a hobby project about evolution, population genetics, ecology, genomics and bioinformatics. The idea is simple: small, playful interactive illustrations that make scientific ideas enjoyable to explore.

The name nods to René Magritte's The Treachery of Images and its inscription, Ceci n'est pas une pipe. A picture of an organism is a representation; a scientific model is one too. Both can help us look more closely.

A note on how it is made

The artwork and code are AI-generated or AI-assisted. The underlying code has not undergone independent human review. The illustrations are intended for educational exploration, rather than scientific research or analysis.

This is a personal project without institutional affiliation.
