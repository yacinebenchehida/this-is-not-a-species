# Illustration assets

Developer reference for the site's raster artwork.

| Asset | Role |
| --- | --- |
| `butterfly-mule.png` | Official header and footer mark. |
| `favicon.png` | Small standalone butterfly–mule icon. |
| `evolutionary-tree.png` | Multicoloured tree used beside the homepage title and on About. |
| `evolution.webp`, `population-genetics.webp`, `ecology.webp`, `genomics.webp`, `bioinformatics.webp` | Theme card illustrations. |
| `genetic-drift.webp`, `predator-prey.webp`, `sequencing-zoom.webp` | Simulation preview illustrations. |
| `hero-landscape.webp` | Panoramic background behind the homepage title. |

The logo and evolutionary tree were extracted from the project's original AI-assisted concept sheet. Theme and simulation illustrations were cropped from the project's AI-assisted homepage artwork. The landscape was generated to match that artwork, then cropped and compressed for web use.

Keep the muted teal, coral and ochre palette and modernist natural-history style. Use these finished illustrations rather than emoji or primitive stand-ins. Supply headings, labels and navigation separately as HTML. Preview artwork is decorative and does not establish that a scientific simulation is implemented.
