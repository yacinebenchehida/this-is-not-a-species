# Illustration assets

The supplied approved homepage (24 October 2026) is the visual source of truth.

- `butterfly-mule.png`: official mark, extracted from the top-right creature on the original eight-concept sheet. Used only in the header/footer; `favicon.png` is its small icon.
- `evolutionary-tree.png`: original bottom-row second tree, isolated without the inscription. Used beside the homepage title and on About.
- Five theme WebPs: cropped from the approved homepage, with all labels supplied separately as HTML. The evolution illustration is intentionally cropped above the original embedded card label.
- `genetic-drift.webp`, `predator-prey.webp`, `sequencing-zoom.webp`: cropped from the approved simulation previews. These are decorative previews, not working applications or literal scientific diagrams.
- `hero-landscape.webp`: newly prepared with the built-in image-generation tool, using the approved revised hero as reference. The generation brief was: a standalone wide warm-cream natural-history landscape with dark teal foreground plants and orange flowers at left, low turquoise mountains and lake, orange flowering tree at right, pale ochre sun and three birds; remove all interface, text, buttons and central tree, leaving cream sky for real HTML content. Cropped and compressed for web display.

All assets are raster artwork; do not replace them with emoji, primitive CSS pictures or generic icons. The supplied references were AI-assisted artwork. Keep the muted teal/coral/ochre palette and modernist natural-history style. No institutional affiliation is implied.
